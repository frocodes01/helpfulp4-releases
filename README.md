# Helpfulp4 releases

Public downloads and updates for Helpfulp4, a DMU Phase 4 assignment helper.

## Installation

Add this URL to Dalamud's custom plugin repositories:

```text
https://raw.githubusercontent.com/frocodes01/helpfulp4-releases/main/repo.json
```

Save the settings, open the plugin installer, and search for Helpfulp4. Testing-plugin opt-in is not required.

If migrating from the previous repository, replace its custom repository URL with the URL above. Keep your existing Helpfulp4 configuration.

This repository contains the download manifest and compiled releases. Source code is maintained separately.
